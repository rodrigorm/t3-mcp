# Issue tracker

**Tracker:** GitHub Issues for this repository (`rodrigorm/t3-mcp`).

**How to create issues:** use the `gh` CLI from the repo root, e.g.

```bash
gh issue create --title "..." --body "..." --label ready-for-agent
```

**PRs as a request surface:** off

Specs produced by `/to-spec` and tickets from `/to-tickets` are published as GitHub Issues in this repo.
