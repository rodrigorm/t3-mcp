# Agent notes

## Domain docs

- Root `CONTEXT.md` (when present) and `docs/adr/` hold domain glossary and ADRs.
- Issue tracker config: `docs/agents/issue-tracker.md`
- Triage labels: `docs/agents/triage-labels.md`

## Agent skills

Engineering skills (`grill-with-docs`, `to-spec`, `to-tickets`, …) are installed under `~/.agents/skills` on the host. Prefer GitHub Issues in this repo for specs and tickets.
